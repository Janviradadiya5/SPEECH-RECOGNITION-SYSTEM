# SPEECH-RECOGNITION-SYSTEM

- **Microphone Input:** Transcribes live spoken input from your microphone.
- **Audio File Input:** Converts speech from a prerecorded WAV audio file into text.

## Features

- **Live Transcription:** Capture and transcribe speech directly from your microphone.
- **Audio File Transcription:** Process and transcribe any readable WAV file.

## Requirements

- **Python 3.6+**
- **SpeechRecognition**  
- **PyAudio** (for microphone support)
